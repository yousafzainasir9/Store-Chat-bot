Store Chat Widget — asset host

This service only serves the embeddable bundle. There's no app to view here — it works like a CDN.

The asset is at /widget.js.

See the chatbot in action

Run the sample storefront, then open http://localhost:8080:

docker compose --profile local up --build

Embed on a real storefront

<script src="http://localhost:8082/widget.js"
        data-api-base="http://localhost:8000"></script>

Admin dashboard: http://localhost:8081  ·  API docs: http://localhost:8000/docs
