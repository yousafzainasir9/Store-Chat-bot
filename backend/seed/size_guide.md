# Women's clothing size guide

## How do I measure myself?
Use a soft tape measure. For bust, measure around the fullest part. For waist, measure around the narrowest part of your torso. For hips, measure around the fullest part of your hips and seat.

## Women's tops and dresses sizing
Size XS fits a 32-33 inch bust and 24-25 inch waist. Size S fits a 34-35 inch bust and 26-27 inch waist. Size M fits a 36-37 inch bust and 28-29 inch waist. Size L fits a 38-40 inch bust and 30-32 inch waist. Size XL fits a 41-43 inch bust and 33-35 inch waist.

## Women's jeans and trouser sizing
A size 26 fits a 26-27 inch waist. A size 28 fits a 28-29 inch waist. A size 30 fits a 30-31 inch waist. A size 32 fits a 32-33 inch waist. Our jeans have roughly 2 percent stretch.

# Men's clothing size guide

## Men's tops sizing
Size S fits a 35-37 inch chest. Size M fits a 38-40 inch chest. Size L fits a 41-43 inch chest. Size XL fits a 44-46 inch chest. Size XXL fits a 47-49 inch chest.

## Men's trouser sizing
Men's trousers are sized by waist and inseam in inches. We offer waist sizes 28 to 40 and inseams of 30, 32, and 34 inches.

## Do your items run true to size?
Most of our items run true to size. Knitwear and relaxed-fit styles run slightly large; if you are between sizes in those styles we recommend sizing down. Tailored and slim-fit styles run slightly small; we recommend sizing up if between sizes.

## How should I care for my garments?
Care instructions are on each product page and the garment label. In general, machine wash cold and lay flat to dry to preserve fit and color. Wool and cashmere items should be hand washed or dry cleaned.
